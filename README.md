# Slovo

**Your voice, wherever you type.**

Slovo turns your voice into text wherever you type, in Bulgarian or English. It works with a server run by someone you trust.

- **Website and download:** https://zlatimirvalkov.github.io/slovo/
- **Installers:** see [Releases](https://github.com/zlatimirvalkov/slovo/releases/latest)

This repository only holds the public website and the installers. It does not contain the source code.
